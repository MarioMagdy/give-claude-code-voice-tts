    The idea

    It reads the summary. Never the code.

    Claude ends a conversational reply with one plain-prose line in a <spoken> tag. The hook speaks only that line. Code blocks, tables and file dumps get no tag at all — so they stay silent by design.

    How it works

    Five steps, one of them kept warm.

    SessionStart hook

    Injects the <spoken> emission rule — but only in projects where you've turned speech on — and makes sure the daemon is alive.

    Claude replies

    One plain-prose line, at the very end, inside the tag. Data-shaped replies deliberately get nothing.

    Stop hook · hook_post.py

    POSTs the reply to a localhost daemon. Token-authenticated, size-bounded, and it rejects non-local file paths.

    The warm daemon · daemon.py

    Stays resident, so there's no Python, import and TLS cold-start on every reply — roughly 2–3× faster than spawning per utterance. It also serialises jobs, so two sessions never talk over each other.

    Playback · Windows MCI

    Synthesised by edge-tts, played through winmm.dll. Cut it off mid-sentence with Ctrl+Alt+S.

    Install

    Two commands, then it's off until you say so.

    /plugin marketplace add MarioMagdy/give-claude-code-voice-tts
    /plugin install voice-tts@give-claude-code-voice-tts

    It is off in every project until you opt one in. Run /speech and choose "Turn speech on". Zero blast radius in repos you didn't enable.

    Before you install it

    The things a landing page usually leaves out.

    Platform
    Windows 10/11 only. Playback goes through MCI via winmm.dll. Synthesis is cross-platform, so macOS and Linux need only a new playback path — it's the most useful thing anyone could contribute.
    Network
    Synthesis is a network call. The one-line spoken summary reaches Microsoft's servers. Your code, tables and file dumps never get the tag, so they never leave — but don't enable speech where sending that one line is unacceptable.
    Backend
    edge-tts rides the undocumented service behind Edge's Read Aloud feature, not a supported public API. It can break without notice. The fallbacks are already chosen and written down: swap voice, pin the version, drop to Windows SAPI, or move to Piper.
